# KernelSU Managers Repository

This repository is simply used to upload and host the KernelSU manager APKs that I use for my custom kernel builds. 

## 📱 Supported Devices
My kernels are built for the following devices:
* Redmi Note 7 (`lavender`)
* Redmi Note 5 / Note 5 Pro (`whyred`)

## 📦 Available Managers
The following manager versions are available in this repository:
* `KernelSU_Next_v33024`
* `KernelSU_Next_v33068`
* `ResukiSU_v34681`
* `ResukiSU_SUSFS_v35107`

## 📥 Download
You can download the APK files directly from the [Releases](https://github.com/ExXyrou/main/releases) page. 

*Note: Please ensure you install the manager version that matches the one integrated into your flashed kernel.*
